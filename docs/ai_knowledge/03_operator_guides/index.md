# Pakhlai system operator knowledge base

Pakhlai System Operator Knowledge Base. Scope: implemented React staff portals and their Django business rules, plus customer-facing handoff context. This is documentation only. Business analytics, metric definitions, marketing pages, chatbot tools, and API integration instructions are outside scope. Evidence snapshot: 2026-10-28.

Start with [application navigation](navigation/application_navigation.md) and the appropriate role guide. Use [page directory](navigation/page_directory.md) to find an exact route or [coverage matrix](coverage_matrix.md) to locate an individual action or field.

The knowledge base contains 48 curated operating, workflow, role, form, troubleshooting and QA guides; 227 interface references; and navigation, backend-contract and source inventories. See the [verification report](qa_report.md) for checked counts and the [implementation verification register](troubleshooting/verification_register.md) for known discrepancies and live acceptance work.
